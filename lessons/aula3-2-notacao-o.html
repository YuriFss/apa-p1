1. Limite superior: a ideia

Dada uma função $f(n)$ que representa o tempo de execução de um algoritmo, a notação $O$ ajuda a determinar um limite superior para ela, por meio de uma função $g(n)$. O tempo do algoritmo não pode ser superior a $g(n)$ a partir de um determinado valor de entrada.

Exemplo dos slides: $f(n) = n^2 - 5n + 8$

Tentativa 1: $g(n) = 10n$. Para $n$ pequeno, $g$ fica acima de $f$ e parece um limite superior. Mas será que é mesmo?

$f(n) \le 10n \iff n^2 - 15n + 8 \le 0$, que só vale entre as raízes, aproximadamente $0{,}55 \le n \le 14{,}45$. A partir de $n = 15$, $f$ passa $g$ e nunca mais volta. Uma parábola sempre acaba ultrapassando uma reta. Logo, $10n$ não é um limite superior para $f$.

No slide, o gráfico mostra o cruzamento perto de $n = 6$, porque a reta desenhada parece ser $n + 9$, e não $10n$. A conclusão é a mesma: depois de certo $n$, a reta deixa de ser limite.

A pergunta do professor: do ponto de vista de uma análise geral, o que interessa mais, o consumo para $n$ pequeno ou para $n$ grande? Para $n$ grande.

2. O primeiro ajuste: $n_0$

Tentativa 2: $g(n) = n^2$. Agora o problema é outro:

$$f(n) \le n^2 \iff n^2 - 5n + 8 \le n^2 \iff 8 \le 5n \iff n \ge 1{,}6.$$

Então $g$ é limite superior somente para $n \ge 2$. Em $n = 0$ ou $n = 1$, $f$ fica acima ($f(1) = 4 > 1$). Mas, como o comportamento para $n$ pequeno não importa:

A constante $n_0$

Usamos uma constante $n_0$ para dizer a partir de que ponto o limite é válido. Aqui, $n_0 = 2$.

Pode parecer "roubado", mas faz parte das simplificações desse tipo de análise: queremos a visão geral do algoritmo.

Como se lê

$f = O(g)$ se lê "a função $f$ está em Ó de $g$", "$f$ está na ordem Ó de $g$" ou "$f$ é Ó de $g$".

Sejam $f(n)$ e $g(n)$ duas funções assintoticamente não negativas. Dizer que $f = O(g)$ significa que $f$ não cresce mais rapidamente que $g$. Nada impede que as duas cresçam na mesma proporção. Por isso, $f = O(g)$ é uma leve analogia a $f \le g$.

3. O segundo ajuste: a constante $c$

Outro exemplo: $f(n) = 2n^2 + 1$. Pela definição informal, $g(n) = n^2$ deveria servir, já que as duas são quadráticas e têm a mesma taxa de crescimento. Mas no gráfico, $g$ fica sempre abaixo de $f$: $n^2 < 2n^2 + 1$ para todo $n$, e nenhum $n_0$ resolve.

A constante $c$

A definição formal resolve isso com uma segunda constante positiva, $c$: mostramos que $f(n)$ não cresce mais rapidamente que $c \cdot g(n)$.

Com $c = 3$: $2n^2 + 1 \le 3n^2 \iff 1 \le n^2 \iff n \ge 1$. Então $c = 3$ e $n_0 = 1$ funcionam. Não é o único valor possível: $c = 2{,}5$ com $n_0 = 2$ também serve. O $c$ "absorve" o coeficiente, e é por isso que coeficientes não importam.

4. Definição formal

Definição (slide 26)

$f(n) = O(g(n))$ se, e somente se:

  • $f$ e $g$ são funções assintoticamente não negativas; e
  • existem duas constantes positivas $c$ e $n_0$ tais que $$f(n) \le c \cdot g(n) \quad \text{para todo } n \ge n_0.$$

Antes de $n_0$, $f$ pode fazer o que quiser. Depois de $n_0$, fica sempre abaixo de $c \cdot g$ (Cormen, figura 3.1b).

Detalhes que caem
  • É para todo $n \ge n_0$, não "para algum" $n \ge n_0$.
  • $f$ e $g$ não podem ser quaisquer funções: precisam ser assintoticamente não negativas.
  • O limite não precisa valer para todo $n$, só a partir de $n_0$.

6. Como provar 1: pela definição ($c$ e $n_0$ explícitos)

Exemplo do slide: o algoritmo $A_1$ tem $f_1(n) = 2n + 20$. Queremos provar que $f_1 = O(n)$. Pela definição, devemos encontrar $c$ e $n_0$ tais que $2n + 20 \le c \cdot n$ para todo $n \ge n_0$.

Caminho A: escolher $c$ e resolver a desigualdade para achar $n_0$

O gráfico do slide sugere $c = 3$:

$$2n + 20 \le 3n \iff 20 \le n.$$

Logo, $c = 3$ e $n_0 = 20$.

Caminho B: escolher $n_0$ e "majorar" termo a termo para achar $c$

Para $n \ge 1$, vale $20 \le 20n$, porque multiplicar 20 por um $n \ge 1$ não diminui. Então:

$$2n + 20 \le 2n + 20n = 22n \quad \text{para todo } n \ge 1.$$

Logo, $c = 22$ e $n_0 = 1$. As duas respostas estão certas: a definição pede que exista um par, não um par específico.

Modelo de redação para a prova

Afirmação: $f_1(n) = 2n + 20 = O(n)$.

Prova: Pela definição, basta mostrar constantes positivas $c$ e $n_0$ tais que $2n + 20 \le c\,n$ para todo $n \ge n_0$. Tome $c = 3$ e $n_0 = 20$. Para todo $n \ge 20$, temos $20 \le n$, logo $2n + 20 \le 2n + n = 3n = c\,n$. Portanto $f_1(n) = O(n)$. ∎

A técnica de majorar, em geral

Para provar que um polinômio é $O(n^k)$, onde $k$ é o maior expoente:

  1. Jogue fora os termos negativos. Eles só diminuem $f$, e se $f$ sem eles está abaixo, $f$ com eles também está.
  2. Suba cada termo positivo para $n^k$, usando que, para $n \ge 1$: $1 \le n \le n^2 \le n^3 \le \dots$
  3. Some os coeficientes: isso dá o $c$. O $n_0$ é 1.

Exemplo: $T_p(n) = 5n^2 + 4n - 7$ (pior caso do InsertionSort). Para $n \ge 1$:

$$5n^2 + 4n - 7 \;\le\; 5n^2 + 4n \;\le\; 5n^2 + 4n^2 \;=\; 9n^2.$$

Logo $T_p(n) = O(n^2)$ com $c = 9$ e $n_0 = 1$.

Exemplo: $T(n) = 9n^2 + n + 2$ (soma de matrizes). Para $n \ge 1$: $9n^2 + n + 2 \le 9n^2 + n^2 + 2n^2 = 12n^2$. Então $c = 12$ e $n_0 = 1$.

7. Como provar que não é $O$

Use contradição: suponha que existem $c$ e $n_0$ e chegue a um absurdo.

Exemplo: $n^2 \ne O(n)$

Suponha, por absurdo, que existem $c > 0$ e $n_0$ com $n^2 \le c\,n$ para todo $n \ge n_0$. Dividindo por $n > 0$: $n \le c$ para todo $n \ge n_0$. Mas isso é falso para $n = \max(n_0, \lceil c \rceil + 1)$, que é $\ge n_0$ e $> c$. Absurdo. Logo $n^2 \ne O(n)$. ∎

A ideia: depois de dividir tudo, sobra "uma coisa que cresce sem limite $\le$ uma constante", e isso nunca vale para todo $n$ grande.

8. Como provar 2: pelo limite (método do gabarito)

É o método que o professor mostra nos slides 31 a 33 e usa no gabarito da lista. Calcule

$$L = \lim_{n \to \infty} \frac{f(n)}{g(n)}$$
ResultadoSignificado$f = O(g)$?
$L = 0$$g$ cresce mais rápido que $f$Sim
$0 < L < \infty$ (uma constante)mesma taxa de crescimentoSim
$L = \infty$$f$ cresce mais rápido que $g$Não

Exemplos dos slides:

$$\lim_{n\to\infty} \frac{2n + 20}{n} = \lim_{n\to\infty}\left(2 + \frac{20}{n}\right) = 2 \;\Rightarrow\; \text{mesma taxa}, \; 2n + 20 = O(n).$$ $$\lim_{n\to\infty} \frac{2n + 20}{n^2} = \lim_{n\to\infty}\left(\frac{2}{n} + \frac{20}{n^2}\right) = 0 \;\Rightarrow\; g \text{ cresce mais rápido}, \; 2n + 20 = O(n^2).$$
Por que o limite funciona (ligação com $c$ e $n_0$)

Se $\lim f/g = L < \infty$, então, para $n$ grande o bastante, $f(n)/g(n)$ fica perto de $L$, em particular abaixo de $L + 1$. Isso dá $f(n) \le (L + 1)\,g(n)$ a partir de algum $n_0$, ou seja, $c = L + 1$. O limite é um atalho que garante que $c$ e $n_0$ existem.

Limites com polinômios: divida pela maior potência de $n$

$$\lim_{n\to\infty} \frac{5n^2 + 4n - 7}{n^2} = \lim_{n\to\infty}\left(5 + \frac{4}{n} - \frac{7}{n^2}\right) = 5.$$

Limites com $\log$, $2^n$, $n!$: regra de L'Hôpital

Quando dá $\frac{\infty}{\infty}$ e não simplifica, derive em cima e embaixo. Isso é necessário na questão 3 da lista. Exemplo:

$$\lim_{n\to\infty} \frac{n \log_2 n}{n^2} = \lim_{n\to\infty} \frac{\log_2 n}{n} \overset{\text{L'H}}{=} \lim_{n\to\infty} \frac{\frac{1}{n \ln 2}}{1} = 0.$$

Logo $n\log n = O(n^2)$. Lembre: $(\log_2 n)' = \frac{1}{n \ln 2}$, $(n^k)' = k\,n^{k-1}$ e $(2^n)' = 2^n \ln 2$.

9. Limite "mais apertado", pior caso e melhor caso

  • Ao analisar algoritmos, queremos a taxa de crescimento mais próxima possível do comportamento real, ou seja, um $g(n)$ com a mesma taxa de crescimento. É o limite superior mais apertado, que é como a lista pergunta na questão 2c.
  • Mas, pela definição, não está incorreto afirmar que $f_1(n) = 2n + 20 = O(n^2)$. Só é um limite folgado.
  • A notação $O$ é muito usada para o pior caso: nele queremos exatamente um limite superior para o tempo, e o algoritmo não requer mais tempo que $O(g(n))$.
  • Usar $O$ no melhor caso é correto? Sim. Mas existe uma notação mais apropriada para o melhor caso. É assunto da Aula 4 ($\Omega$ e $\Theta$).
