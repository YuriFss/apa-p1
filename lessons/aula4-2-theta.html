1. Definição: o sanduíche

A notação $\Theta$ define tanto um limite inferior quanto um superior. Ele se chama limite assintoticamente restrito. O professor chama de "sanduíche de uma função": $f(n)$ é o recheio, e as fatias de pão são duas cópias de $g(n)$, uma multiplicada por $c_1$ e outra por $c_2$.

Definição (slide 22)

$f(n) = \Theta(g(n))$ se, e somente se, existem constantes positivas $c_1$, $c_2$ e $n_0$ tais que

$$c_1\,g(n) \;\le\; f(n) \;\le\; c_2\,g(n) \quad \text{para todo } n \ge n_0.$$

Analogia: $f = \Theta(g)$ é como "$f = g$" em taxa de crescimento: crescem na mesma proporção.

2. Exemplo do slide: $n^2 - 3n + 3 = \Theta(n^2)$

Devemos provar que existem $c_1$, $c_2$ e $n_0$ tais que $c_1 n^2 \le n^2 - 3n + 3 \le c_2 n^2$ para todo $n \ge n_0$. O slide escolhe $n_0 = 1$, $c_1 = 0{,}2$ e $c_2 = 1$. Vamos provar as duas metades separadamente.

Lado de cima: $n^2 - 3n + 3 \le 1 \cdot n^2$

$$n^2 - 3n + 3 \le n^2 \iff -3n + 3 \le 0 \iff n \ge 1. \;\checkmark$$

Lado de baixo: $0{,}2\,n^2 \le n^2 - 3n + 3$

$$0{,}2\,n^2 \le n^2 - 3n + 3 \iff 0 \le 0{,}8\,n^2 - 3n + 3.$$

O discriminante de $0{,}8\,n^2 - 3n + 3$ é $\Delta = 9 - 4 \cdot 0{,}8 \cdot 3 = 9 - 9{,}6 = -0{,}6 < 0$. Uma parábola com coeficiente líder positivo e sem raízes reais é sempre positiva. Logo vale para todo $n$. ✓

As duas metades valem para $n \ge 1$, então $n^2 - 3n + 3 = \Theta(n^2)$ com $c_1 = 0{,}2$, $c_2 = 1$ e $n_0 = 1$. ∎

De onde veio o 0,2? (como achar $c_1$ sozinho)

Olhe para a razão $\dfrac{f(n)}{g(n)} = \dfrac{n^2 - 3n + 3}{n^2} = 1 - \dfrac{3}{n} + \dfrac{3}{n^2}$:

$n$123410100
$f(n)/n^2$10,250,330,440,730,97

A razão nunca passa de 1, então $c_2 = 1$ serve. O menor valor é $0{,}25$, em $n = 2$, então qualquer $c_1 \le 0{,}25$ serve a partir de $n_0 = 1$. O professor escolheu $0{,}2$. Para $n$ grande a razão tende a 1, que é o limite $\lim f/g = 1$.

4. Teorema: $\Theta \iff O$ e $\Omega$

Teorema (slide 25)

Para quaisquer funções $f(n)$ e $g(n)$:

$$f(n) = \Theta(g(n)) \iff f(n) = \Omega(g(n)) \;\text{ e }\; f(n) = O(g(n)).$$

Podemos usar esse teorema para provar um limite assintótico restrito por meio de limites superiores e inferiores: prove $O(g)$, prove $\Omega(g)$ e conclua $\Theta(g)$. Esse é um formato comum de resposta na lista.

Na prática: a parte $O$ dá o $c_2$ e a parte $\Omega$ dá o $c_1$. O $n_0$ do $\Theta$ é o maior dos dois $n_0$, para que as duas desigualdades valham ao mesmo tempo.

Exemplo: $5n^2 + 4n - 7$ (pior caso do InsertionSort). Na lição 3.2: $\le 9n^2$ para $n \ge 1$. Na lição 4.1: $\ge 4n^2$ para $n \ge 3$. Logo, $5n^2 + 4n - 7 = \Theta(n^2)$ com $c_1 = 4$, $c_2 = 9$ e $n_0 = \max(1, 3) = 3$.

O professor também costuma calcular o limite inverso, $\lim g/f$: se os dois são finitos, nenhuma das funções cresce mais rápido que a outra, e as duas têm a mesma taxa.

6. Melhor caso, pior caso e "qualquer entrada"

Propriedades (slide 26)
  • Melhor caso analisado com $\Omega$: dá um limite inferior para o tempo do algoritmo sob qualquer entrada. Nenhuma entrada custa menos que o melhor caso.
  • Pior caso analisado com $O$: dá um limite superior para o tempo sob qualquer entrada. Nenhuma entrada custa mais que o pior caso.

Pergunta do slide 28: o pior caso do InsertionSort tem taxa $O(n^2)$. Podemos afirmar que $\Theta(n^2)$ é um limite válido para o InsertionSort sob qualquer entrada?

Não! O melhor caso é $\Theta(n)$. Com o vetor ordenado, o algoritmo gasta $13n - 11$, que não é $\Omega(n^2)$. Uma afirmação "sob qualquer entrada" precisa valer também para o melhor caso.

Afirmação sobre o InsertionSortVálida?
Pior caso é $\Theta(n^2)$✔ ($5n^2 + 4n - 7$)
Melhor caso é $\Theta(n)$✔ ($13n - 11$)
$O(n^2)$ sob qualquer entrada✔ (o pior caso limita tudo por cima)
$\Omega(n)$ sob qualquer entrada✔ (o melhor caso limita tudo por baixo)
$\Theta(n^2)$ sob qualquer entrada✘ (o melhor caso não é $\Omega(n^2)$)
$\Theta(n)$ sob qualquer entrada✘ (o pior caso não é $O(n)$)

Regra geral: existe um $\Theta(g)$ válido sob qualquer entrada se, e somente se, o melhor caso e o pior caso são ambos $\Theta(g)$. Exemplo: o SelectionSort tem melhor caso $3n^2 + 3n - 5$, e o pior caso também é quadrático, então ele é $\Theta(n^2)$ para qualquer entrada.
