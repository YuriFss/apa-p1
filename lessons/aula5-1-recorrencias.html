1. Algoritmos recursivos

Até o momento, todos os algoritmos eram iterativos, e a função $f(n)$ do tempo de execução era relativamente fácil de identificar. A partir de agora, a função do tempo de execução passa a ser chamada de $T(n)$.

Definição (slide 3)

Algoritmo recursivo é aquele que chama a si mesmo durante sua execução.

Exemplo: o fatorial. Para $n = 4$: $4! = 4 \cdot 3!$, $3! = 3 \cdot 2!$, $2! = 2 \cdot 1!$, $1! = 1 \cdot 0!$ e $0! = 1$. Em geral, $n! = n \cdot (n-1)!$.

fatorial(n)
1.  if n = 0:
2.      return 1
3.  else
4.      return fatorial(n−1) * n      ← algoritmo recursivo!
Chamadas de fatorial(n): uma corrente

Cada chamada faz uma chamada menor e uma multiplicação. São $n + 1$ chamadas no total, de $n$ até $0$.

Como descrever o tempo de execução $T(n)$ de um algoritmo assim? Por meio de uma recorrência.

2. Recorrência: definição

Definição (slide 7)

Recorrência é uma equação ou desigualdade que descreve uma função em termos de seu próprio valor para entradas menores.

Recorrência do fatorial:

$$\begin{cases} T(0) = 1 & \leftarrow \text{caso base} \\ T(n) = T(n-1) + 1 & \leftarrow \text{passo recursivo} \end{cases}$$
  • O número total de passos para $n!$ é o número de passos para resolver $(n-1)!$, que é $T(n-1)$, mais 1 passo.
  • Esse "+1" é a operação de tempo constante feita em cada chamada: a multiplicação.
  • O caso base é onde a recursão para. Sem ele, a equação não define nada.
Como montar a recorrência de um algoritmo recursivo
  1. Caso base: quanto custa quando a recursão para? Aqui, $T(0) = 1$.
  2. Chamadas recursivas: quantas são, e com que tamanho? Aqui, uma chamada com $n-1$, ou seja, $T(n-1)$.
  3. Trabalho fora das chamadas: quanto a chamada atual faz por conta própria? Aqui, uma multiplicação: $+1$.

$T(n) = (\text{número de chamadas}) \times T(\text{tamanho menor}) + (\text{trabalho próprio})$.

3. Fórmula fechada e métodos

A complexidade de um algoritmo recursivo envolve resolver sua recorrência. Em $T(n) = T(n-1) + 1$, precisamos saber quantos passos são executados em $T(n-1)$, que depende de $T(n-2)$, e assim por diante.

O objetivo é encontrar uma fórmula fechada: uma expressão sem $T$ do lado direito, geralmente uma combinação de polinômios, logaritmos, exponenciais etc.

Existem diversas técnicas:

  • método iterativo, o foco da disciplina pela simplicidade;
  • método de substituição;
  • método mestre (aparece na divisão e conquista, Aulas 6 e 7).

4. Método iterativo, passo a passo

O método (slide 10)
  1. Expandir a recorrência, simulando múltiplas iterações (chamadas).
  2. Usar propriedades algébricas para encontrar um somatório, ou seja, o padrão depois de $k$ passos.
  3. Resolver o somatório e encontrar uma fórmula fechada.

Fatorial: $T(0) = 1$, $T(n) = T(n-1) + 1$ para $n \ge 1$

Observe que a mesma regra vale para qualquer argumento. Basta trocar $n$ por $n-1$, $n-2$, …:

$$\begin{aligned} T(n) &= T(n-1) + 1\\ T(n-1) &= T(n-2) + 1\\ T(n-2) &= T(n-3) + 1 \end{aligned}$$

Expandir é substituir cada $T(\cdot)$ pela sua própria definição:

Expansão, um passo por clique

Depois de $k$ passos, o padrão é:

$$T(n) = T(n-k) + k.$$

Quando a expansão termina? No caso base, onde a recursão termina. Aqui o caso base é $T(0)$, então:

$$n - k = 0 \iff k = n.$$

Substituindo $k = n$:

$$T(n) = T(n - n) + n = T(0) + n = 1 + n.$$

$T(n) = n + 1 = \Theta(n)$

Confira: $T(0) = 1$, $T(1) = T(0) + 1 = 2$, $T(2) = 3$, $T(3) = 4$. A fórmula $n + 1$ dá 1, 2, 3, 4 ✓. Conferir os primeiros valores pela recorrência é a forma mais rápida de pegar erro.

Formato que o gabarito usa
  1. Escreva $T(n)$, $T(n-1)$, $T(n-2)$, $T(n-3)$ "observando o comportamento".
  2. Expanda marcando passo 1, passo 2, passo 3, passo 4.
  3. Escreva "após $k$ passos" com um somatório.
  4. Iguale o argumento ao caso base e resolva para $k$.
  5. Substitua, resolva o somatório (PA ou PG) e simplifique.

5. As duas somas que você vai usar: PA e PG

PA (soma de termos que crescem de forma constante)

$$\sum_{i=1}^{k} i = \frac{k(k+1)}{2} \qquad\text{e, em geral,}\qquad \text{soma} = \frac{(\text{nº de termos})\,(\text{primeiro} + \text{último})}{2}.$$

PG (soma de potências)

$$\sum_{i=0}^{k-1} r^i = 1 + r + r^2 + \dots + r^{k-1} = \frac{r^k - 1}{r - 1} \qquad (r \ne 1).$$
Por que a fórmula da PG vale

Seja $S = 1 + r + \dots + r^{k-1}$. Multiplique por $r$: $rS = r + r^2 + \dots + r^k$. Subtraia: $rS - S = r^k - 1$, quase tudo se cancela. Logo $S = \frac{r^k - 1}{r - 1}$.

Caso mais comum, $r = 2$: $1 + 2 + 4 + \dots + 2^{k-1} = 2^k - 1$. É a Torre de Hanói (lição 5.2).

6. Exemplo extra: uma recorrência que vira PA

$T(1) = 1$ e $T(n) = T(n-1) + (2n - 1)$ para $n > 1$. Agora o trabalho próprio depende de $n$.

Observando: $T(n-1) = T(n-2) + (2(n-1) - 1) = T(n-2) + (2n - 3)$, e $T(n-2) = T(n-3) + (2n - 5)$.

$$\begin{aligned} T(n) &= T(n-1) + (2n-1) && \text{passo 1}\\ &= T(n-2) + (2n-3) + (2n-1) && \text{passo 2}\\ &= T(n-3) + (2n-5) + (2n-3) + (2n-1) && \text{passo 3}\\ &= T(n-k) + \sum_{i=0}^{k-1} \big(2(n-i) - 1\big) && \text{passo } k \end{aligned}$$

Caso base: $n - k = 1 \iff k = n - 1$. Substituindo:

$$T(n) = T(1) + \underbrace{(2n-1) + (2n-3) + \dots + 3}_{n-1 \text{ termos (ímpares de 3 a } 2n-1)}.$$

É uma PA com $n - 1$ termos, primeiro $3$ e último $2n - 1$: soma $= \frac{(n-1)(3 + 2n - 1)}{2} = \frac{(n-1)(2n+2)}{2} = (n-1)(n+1) = n^2 - 1$.

$$T(n) = 1 + n^2 - 1 = n^2.$$

$T(n) = n^2 = \Theta(n^2)$

Confira: $T(1) = 1$, $T(2) = 1 + 3 = 4$, $T(3) = 4 + 5 = 9$, $T(4) = 9 + 7 = 16$. São os quadrados ✓.

Erros clássicos
  • Esquecer que $T(n-1)$ usa $n-1$ também no termo extra: $T(n-1) = T(n-2) + 2(n-1) - 1$, e não $+\,2n - 1$.
  • Errar o caso base: se a base é $T(1)$, então $n - k = 1$ e não $n - k = 0$.
  • Contar errado o número de termos do somatório: vai de $i = 0$ a $k - 1$, que são $k$ termos.
