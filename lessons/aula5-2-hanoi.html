Torre de Hanói: uma recorrência exponencial

Slides 15 a 24 da Aula 5. É o exemplo clássico para pensar recursivamente, e a recorrência dele resolve por PG: $T(n) = 2^n - 1$.

1. O problema

São três postes (A, B e C) e $n$ discos de tamanhos diferentes, que deslizam pelos postes. No início, todos os discos estão no poste A, do maior (embaixo) para o menor (em cima). O objetivo é levar todos para o poste C, seguindo as regras:

  1. mover um disco de cada vez;
  2. um disco maior não pode ficar sobre um menor.

2. A estratégia recursiva

Resolver esse problema é um bom exercício de como pensar recursivamente: é preciso entender o caso base e como reduzir o problema a uma instância menor. A estratégia básica:

  1. Mover $n - 1$ discos do poste origem para o intermediário. É o mesmo problema, com um disco a menos.
  2. Mover 1 disco, o disco base (o maior), da origem para o destino. Ele está livre, porque os outros saíram de cima.
  3. Mover $n - 1$ discos do intermediário para o destino, em cima do maior.

O "truque": você não precisa saber como mover $n-1$ discos. Basta confiar que a mesma função faz isso. Caso base: com 1 disco, é só movê-lo.

hanoi(n, A, C, B)
1.  if n = 1 then
2.      movaDisco(A, C)          // move de A para C
3.  else
4.      hanoi(n−1, A, B, C)      // move n−1 discos de A para B
5.      movaDisco(A, C)          // move a base para C
6.      hanoi(n−1, B, C, A)      // move n−1 discos de B para C

Ordem dos parâmetros: hanoi(quantos, origem, destino, auxiliar). Na linha 4, o destino vira B e o auxiliar vira C.

3. Animação

hanoi(n, A, C, B) passo a passo

Laranja: o disco que acabou de mover. A variável "pilha" mostra a cadeia de chamadas ativas. Com $n = 3$ são $7$ movimentos, como no slide 18.

4. A recorrência

Seja $T(n)$ o número de movimentos para $n$ discos. Lendo o pseudocódigo:

  • Caso base (linhas 1–2): com 1 disco, 1 movimento. $T(1) = 1$.
  • Linha 4: $T(n-1)$ movimentos.
  • Linha 5: 1 movimento.
  • Linha 6: mais $T(n-1)$ movimentos.
$$\begin{cases} T(1) = 1 \\ T(n) = 1 + 2\,T(n-1) & \text{para } n \ge 2 \end{cases}$$

A diferença para o fatorial é o 2: cada chamada faz duas chamadas menores. Isso transforma uma corrente numa árvore, e a soma linear vira uma PG.

5. Árvore de recursão

Chamadas de hanoi(n): cada nó faz 1 movimento

No nível $d$ (raiz = nível 0) há $2^d$ chamadas, cada uma fazendo 1 movimento próprio (linha 2 ou linha 5). Os níveis vão de $0$ a $n - 1$:

$$T(n) = \underbrace{1}_{\text{nível }0} + \underbrace{2}_{\text{nível }1} + \underbrace{4}_{\text{nível }2} + \dots + \underbrace{2^{n-1}}_{\text{nível }n-1} = \sum_{i=0}^{n-1} 2^i = 2^n - 1.$$

6. Resolvendo pelo método iterativo

Observando: $T(n-1) = 2T(n-2) + 1$, $T(n-2) = 2T(n-3) + 1$, …

$$\begin{aligned} T(n) &= 2\,T(n-1) + 1 && \text{passo 1}\\ &= 2\big(\textcolor{#2a78d6}{2\,T(n-2) + 1}\big) + 1\\ &= 2^2\,T(n-2) + 2 + 1 && \text{passo 2}\\ &= 2^2\big(\textcolor{#2a78d6}{2\,T(n-3) + 1}\big) + 2 + 1\\ &= 2^3\,T(n-3) + 4 + 2 + 1 && \text{passo 3}\\ &\;\;\vdots\\ &= 2^k\,T(n-k) + 2^{k-1} + \dots + 2^2 + 2 + 1 && \text{passo } k \end{aligned}$$

Repare que distribuir o 2 multiplica tudo que está dentro do parêntese: $2 \cdot (2T + 1) = 2^2 T + 2$. É aí que os termos $1, 2, 4, \dots$ aparecem.

Caso base: $n - k = 1$, ou seja, $k = n - 1$ (passos para atingir a base):

$$T(n) = 2^{n-1}\cdot T(1) + 2^{n-2} + \dots + 2^2 + 2 + 1 = 2^{n-1} + 2^{n-2} + \dots + 2 + 1 = \sum_{i=0}^{n-1} 2^i.$$

Pela PG de razão 2: $\displaystyle\sum_{i=0}^{n-1} 2^i = \frac{2^n - 1}{2 - 1} = 2^n - 1$.

$T(n) = 2^n - 1 = \Theta(2^n)$

Confira: $T(1) = 1$, $T(2) = 2\cdot 1 + 1 = 3$, $T(3) = 2\cdot 3 + 1 = 7$, $T(4) = 15$. A fórmula $2^n - 1$ dá 1, 3, 7, 15 ✓.

7. A lenda dos 64 discos

A Torre de Hanói tem pouco a ver com a cidade de Hanói. O registro mais antigo é de Édouard Lucas, em 1893. Ele relata que no templo de Kashi Vishwanath, em Varanasi, na Índia, há 64 discos de ouro em 3 agulhas de diamante, a "Torre de Brahma", que monges tentam resolver desde o início dos tempos. O universo acabaria quando eles terminassem.

  • $2^{64} - 1 \approx 1{,}84 \times 10^{19}$ movimentos.
  • A 1 movimento por segundo: $\frac{1{,}84\times10^{19}}{3{,}15\times 10^{7}\ \text{s/ano}} \approx 5{,}8 \times 10^{11}$ anos, cerca de 42 vezes a idade do universo ($1{,}38 \times 10^{10}$ anos).

O slide escreve "$1{,}38\times10^{10}$ anos" ao lado do resultado, mas esse número é a idade do universo. O tempo total é cerca de $5{,}8 \times 10^{11}$ anos, o que bate com as "42 vezes".

Exercício 5.2
  1. Quantos movimentos são necessários para 10 discos? Confira calculando $T(10)$ pela recorrência a partir de $T(1)$ e pela fórmula fechada.

  4. Por que a recorrência $T(n) = 2T(n-1) + 1$ é exponencial, mas $T(n) = T(n-1) + 1$ é linear? Explique pelo formato da árvore de recursão.
