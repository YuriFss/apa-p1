Questão 1(a): melhor caso, pior caso e contagem de passos

Vale 2,0 pontos, o item mais pesado da prova. É exatamente o que treinamos nas Aulas 1 e 2: identificar o que varia, descrever as entradas e preencher a tabela "# operações / # execuções" para os dois casos.

O enunciado

Questão 1

Considere o pseudocódigo abaixo referente ao seguinte problema: "Dado um vetor contendo $n$ números inteiros não-negativos, verifique se todos os elementos são únicos no vetor."

1  Função VerificaTodosUnicos(vetor, n)
2     para i ← 0 até n − 2 faça
3        para j ← i + 1 até n − 1 faça
4           se vetor[i] == vetor[j] então
5              retorna False
6     retorna True

a) (2,0 pts) Considerando uma análise em relação ao tempo de execução, explique quando ocorrem o melhor caso e o pior caso do algoritmo. Em seguida, realize a contagem de passos do algoritmo em ambos os casos e encontre as respectivas funções $T(n)$. Utilize a tabela ao lado do algoritmo para realizar a contagem de passos de cada linha.

Passo 1: entender o algoritmo

O algoritmo compara todos os pares $(i, j)$ com $i < j$:

  • o laço de fora fixa a posição $i$, de $0$ até $n-2$ (o último elemento não tem com quem ser comparado "para a frente");
  • o laço de dentro compara $\text{vetor}[i]$ com todo mundo depois dele, de $i+1$ até $n-1$;
  • se achar dois iguais, para na hora e retorna False (linha 5);
  • se terminar os dois laços sem achar repetido, retorna True (linha 6).
A pergunta-chave

O que faz o número de passos variar? O retorna False dentro dos laços. Assim que um par igual aparece, tudo para. Então quanto mais cedo aparecer um par repetido, menos passos. Se nunca aparecer, o algoritmo percorre todos os pares.

Passo 2: melhor e pior caso (o "explique")

Melhor caso

Quando os dois primeiros elementos são iguais ($\text{vetor}[0] = \text{vetor}[1]$). A primeira comparação feita ($i = 0$, $j = 1$) já é verdadeira, e o algoritmo retorna False imediatamente. O número de passos não depende de $n$.

Pior caso

Quando todos os elementos são distintos. O teste da linha 4 nunca é verdadeiro, então os dois laços rodam completos: todos os $\frac{n(n-1)}{2}$ pares são comparados e o algoritmo termina na linha 6.

(Empata com o pior caso a entrada em que o único par repetido é o último a ser comparado, $\text{vetor}[n-2] = \text{vetor}[n-1]$: também faz todas as comparações. Basta citar "todos distintos".)

Erro que custa ponto

Não diga "o melhor caso é quando $n$ é pequeno". O melhor caso é uma arrumação dos dados para um $n$ qualquer (Aula 1). Também evite "o melhor caso é quando tem elemento repetido": um repetido no fim do vetor gera o pior caso! O que importa é onde está o par.

Passo 4: a coluna "# execuções" no melhor caso

Com $\text{vetor}[0] = \text{vetor}[1]$:

  1. Linha 2: entra no laço de fora uma vez ($i = 0$) → 1.
  2. Linha 3: entra no laço de dentro uma vez ($j = 1$) → 1.
  3. Linha 4: compara $\text{vetor}[0]$ com $\text{vetor}[1]$ uma vez → 1. Dá verdadeiro.
  4. Linha 5: retorna False → 1.
  5. Linha 6: nunca é alcançada → 0.

Passo 5: a coluna "# execuções" no pior caso

Com todos distintos:

  • Linha 2: $i$ vai de $0$ a $n-2$: $(n-2) - 0 + 1 = $ $n - 1$ iterações.
  • Linhas 3 e 4: para cada $i$, $j$ vai de $i+1$ a $n-1$: são $(n-1) - (i+1) + 1 = n - 1 - i$ iterações. Somando:
valor de $i$012…$n-2$
iterações de $j$$n-1$$n-2$$n-3$…$1$
$$\sum_{i=0}^{n-2}(n-1-i) = (n-1) + (n-2) + \dots + 1 = \frac{(n-1)\,\big((n-1) + 1\big)}{2} = \frac{n(n-1)}{2}.$$

É uma PA com $n - 1$ termos, primeiro $n-1$ e último $1$: a fórmula $S = \frac{\text{termos}}{2}(a_1 + a_n)$ da tabela da prova dá $\frac{n-1}{2}(n - 1 + 1) = \frac{n(n-1)}{2}$.

  • Linha 5: nunca → 0.
  • Linha 6: uma vez → 1.

Convenção do professor (Aula 1): o cabeçalho de cada laço tem o mesmo número de execuções do corpo; o teste final que falha não é contado.

Cada quadrado azul é uma comparação da linha 4 no pior caso (par $(i, j)$ com $j > i$)

Passo 7: as funções $T(n)$

Melhor caso

$$T_m(n) = 2\cdot1 + 3\cdot1 + 3\cdot1 + 1\cdot1 + 1\cdot0 = 9.$$

$T_m(n) = 9$ (constante)

Pior caso

$$\begin{aligned} T_p(n) &= 2(n-1) + 3\cdot\frac{n(n-1)}{2} + 3\cdot\frac{n(n-1)}{2} + 1\cdot 0 + 1\cdot1\\ &= 2n - 2 + 6\cdot\frac{n^2 - n}{2} + 1\\ &= 2n - 2 + 3n^2 - 3n + 1\\ &= 3n^2 - n - 1. \end{aligned}$$

$T_p(n) = 3n^2 - n - 1$

Confira com $n = 2$ (sempre faça isso na prova)

Com 2 elementos distintos: linha 2 uma vez (2), linha 3 uma vez (3), linha 4 uma vez (3), linha 6 (1). Total $9$. Fórmula: $3\cdot4 - 2 - 1 = 9$ ✓. Com $n = 3$: duas voltas do laço de fora ($2\cdot2 = 4$) + três pares comparados, cada um com linha 3 e linha 4 ($3\cdot(3+3) = 18$) + retorno (1) $= 23$. Fórmula: $27 - 3 - 1 = 23$ ✓.

Faz sentido que $T_m(2) = T_p(2) = 9$: com 2 elementos só existe uma comparação a fazer.

Passo 8: confira na animação

VerificaTodosUnicos com a tabela sendo preenchida

Ao final, o total bate com $9$ (melhor caso) ou $3n^2 - n - 1$ (pior caso). Os testes finais dos laços, em cinza, não entram na contagem.

Como escrever na prova

Modelo de resposta

Melhor caso: ocorre quando $\text{vetor}[0] = \text{vetor}[1]$: a primeira comparação já encontra uma repetição e o algoritmo retorna False sem continuar os laços.

Pior caso: ocorre quando todos os elementos são distintos: nenhuma comparação é verdadeira, os dois laços executam por completo e todos os $n(n-1)/2$ pares são comparados.

[tabela preenchida]

$T_m(n) = 2 + 3 + 3 + 1 = 9$.

$T_p(n) = 2(n-1) + 3\frac{n(n-1)}{2} + 3\frac{n(n-1)}{2} + 1 = 3n^2 - n - 1$.
