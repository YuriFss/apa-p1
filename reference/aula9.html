Aula 9: HeapSort

Heap binário (índices a partir de 0)

  • Array visto como árvore binária praticamente completa, lida nível por nível. $A[0]$ é a raiz.
  • $\text{Pai}(i) = \lfloor (i-1)/2 \rfloor$, $\text{Esq}(i) = 2i+1$, $\text{Dir}(i) = 2i+2$.
  • Folhas: índices $\lfloor n/2\rfloor$ a $n-1$. Altura: $\lfloor \log_2 n \rfloor$.
  • Atributos: comprimento[A] e tamanho_heap[A] $\le$ comprimento[A].
  • Heap máximo: $A[\text{Pai}(i)] \ge A[i]$; o máximo fica na raiz. Heap mínimo: $\le$.

Algoritmos

MaxHeapify(A, i)
L ← 2i+1; R ← 2i+2; maior ← i
if L < tam and A[L] > A[maior]: maior ← L
if R < tam and A[R] > A[maior]: maior ← R
if maior ≠ i:
   trocar(A[i], A[maior])
   MaxHeapify(A, maior)
BuildMaxHeap(A)
for i ← ⌊n/2⌋−1 downto 0:
   MaxHeapify(A, i)

HeapSort(A)
BuildMaxHeap(A)
for i ← n−1 downto 1:
   trocar(A[0], A[i]); tam−−
   MaxHeapify(A, 0)
  • Slide usa "L ≤ tamanho_heap" (herança do Cormen, que indexa a partir de 1). Com índice 0, use "<".
  • Exemplo do slide: MaxHeapify(A, 1) em [1,16,5,30,27,17,20,2,57,3,90] dá [1,30,5,57,27,17,20,2,16,3,90].
  • BuildMaxHeap do mesmo array (MaxHeapify em 4, 3, 2, 1, 0) dá [90,57,20,30,27,17,5,2,1,3,16].

  • Ordena no próprio vetor; não é estável; assintoticamente ótimo por comparação.
