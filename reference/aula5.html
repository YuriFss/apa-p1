Aula 5: Recorrências

Definições

  • Algoritmo recursivo: chama a si mesmo durante a execução.
  • Recorrência: equação ou desigualdade que descreve uma função em termos de seu próprio valor para entradas menores. Tem caso base + passo recursivo.
  • Fórmula fechada: expressão sem $T$ do lado direito.
  • Métodos: iterativo (foco), substituição, mestre.

Montar a recorrência

$T(n) = (\text{número de chamadas}) \cdot T(\text{tamanho menor}) + (\text{trabalho próprio})$, mais o caso base.

Método iterativo

  1. Escreva $T(n)$, $T(n-1)$, $T(n-2)$, …, trocando $n$ em todos os lugares.
  2. Expanda (passo 1, 2, 3…) e ache o padrão "após $k$ passos".
  3. Iguale o argumento ao caso base: $n - k = 0$ ou $n - k = 1$, e resolva para $k$.
  4. Substitua, resolva o somatório e simplifique. Confira com $T$ pequeno.

Somas

$$\sum_{i=1}^{k} i = \frac{k(k+1)}{2} \qquad \sum_{i=0}^{k-1} r^i = \frac{r^k - 1}{r - 1} \qquad \sum_{i=0}^{k-1} 2^i = 2^k - 1$$

PA: soma $= \frac{\text{termos}\cdot(\text{primeiro} + \text{último})}{2}$.

Resultados

RecorrênciaApós $k$ passosBaseSolução
Fatorial: $T(0) = 1$, $T(n) = T(n-1) + 1$$T(n-k) + k$$k = n$$n + 1 = \Theta(n)$
$T(1) = 1$, $T(n) = T(n-1) + 2n - 1$$T(n-k) + \sum_{i=0}^{k-1}(2(n-i)-1)$$k = n-1$$n^2 = \Theta(n^2)$
Hanói: $T(1) = 1$, $T(n) = 2T(n-1) + 1$$2^k T(n-k) + \sum_{i=0}^{k-1} 2^i$$k = n-1$$2^n - 1 = \Theta(2^n)$

Torre de Hanói

  • Regras: um disco por vez; maior nunca sobre menor.
  • Estratégia: $n-1$ de origem → intermediário; base → destino; $n-1$ de intermediário → destino.
  • Árvore: nível $d$ tem $2^d$ chamadas; níveis de 0 a $n-1$.
  • 64 discos: $\approx 1{,}84\times10^{19}$ movimentos; a 1/s, cerca de $5{,}8\times10^{11}$ anos (~42× a idade do universo).
