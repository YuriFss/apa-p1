Aula 2: Análise assintótica (Parte 2)

Simplificações, ordenação, InsertionSort e SelectionSort.

Notação

  • $T_m(n)$: $T(n)$ do melhor caso. $T_p(n)$: $T(n)$ do pior caso.
  • cont++ vale 1 op na contagem do professor.

Limite das simplificações

  • Supor operação básica = tempo constante vale enquanto os números cabem em 32/64 bits.
  • A soma de dois números de $n$ bits custa tempo ∝ número de bits.
  • $F_n$ tem cerca de $0{,}694\,n$ bits. $F_{47}$ estoura o int de 32 bits com sinal. Para $n$ grande, fibonacci2 custa ∝ $n^2$ operações de bit (Dasgupta 0.3).

Ordenação

  • Rearranjar objetos em ordem (ascendente ou decrescente). Facilita a recuperação posterior (busca binária).
  • A maioria é baseada em comparações ($>, <, =$). Existem métodos sem comparação (CountingSort, Aula 8).
  • Fatores na escolha: complexidade assintótica, tamanho $n$, complexidade da implementação, restrições de hardware.
  • Simples: bons para $n$ pequeno, complexidade maior, código fácil. Eficientes: bons para $n$ grande, complexidade menor, código mais difícil.

InsertionSort

InsertionSort(A, n)
1. pivo ← null
2. for i ← 1 to n − 1:
3.    pivo ← A[i]
4.    j ← i − 1
5.    while j ≥ 0 and A[j] > pivo:
6.       A[j+1] ← A[j]
7.       j ← j − 1
8.    A[j+1] ← pivo
9. return A

SelectionSort

SelectionSort(A, n)
1. for i ← 0 to n − 2:
2.    i_min ← i
3.    for j ← i+1 to n − 1:
4.       if A[j] < A[i_min]:
5.          i_min ← j
6.    if A[i] ≠ A[i_min]:
7.       temp ← A[i]
8.       A[i] ← A[i_min]
9.       A[i_min] ← temp
10.return A

Piorexercício do slide 43 (lição 2.3)
  • Os laços das linhas 1 e 3 não dependem do conteúdo: o algoritmo é sempre quadrático.
  • A linha 5 varia com os dados, "mas a diferença é somente por um fator constante".
  • Faz no máximo $n-1$ trocas.

Somas que apareceram

$$\sum_{i=1}^{n-1} i = \frac{(n-1)(1 + n - 1)}{2} = \frac{n^2-n}{2} \qquad \sum_{i=0}^{n-2}(n-1-i) = \frac{(n-1)(n-1+1)}{2} = \frac{n^2-n}{2}$$

Fórmula de bolso: $\#\text{exec} = V \cdot \frac{p + u}{2}$, onde $V$ = voltas do laço de fora, $p$ = iterações na primeira volta e $u$ = iterações na última.

Truque de conta

Agrupe as linhas com o mesmo # exec e some os # op delas antes de multiplicar. Exemplo do Insertion no pior caso: linhas 2, 3, 4, 8 → $2+2+2+3 = 9$; linhas 5, 6, 7 → $4+4+2 = 10$.
