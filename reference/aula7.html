Aula 7: Divisão e conquista (Parte II)

MergeSort

mergeSort(A, p, r)
1. if p < r:
2.    q = floor((p+r)/2)
3.    mergeSort(A, p, q)
4.    mergeSort(A, q+1, r)
5.    merge(A, p, q, r)
merge(A, p, q, r)
1-2. L ← A[p..q]; R ← A[q+1..r]
3-4. L e R recebem INF no fim
5.   i ← j ← 1
6.   for k ← p to r:
7.     if L[i] <= R[j]: A[k] ← L[i]; i++
10.    else: A[k] ← R[j]; j++
  • merge custa $\Theta(n)$; a sentinela INF dispensa testar se um lado acabou.
  • Não há melhor nem pior caso: divide sempre igual, independentemente dos dados.
  • $T(1) = 1$, $T(n) = T(\lceil n/2\rceil) + T(\lfloor n/2\rfloor) + cn$. Com $n = 2^k$: $T(n) = 2T(n/2) + n$ ($a = 2, b = 2, f(n) = n$).
  • Árvore: $n$ por nível, $\log_2 n + 1$ níveis. Iterativo: $2^kT(n/2^k) + kn$, $k = \log_2 n$, logo $T(n) = n\log_2 n + n = \Theta(n\log n)$.
  • Memória extra $\Theta(n)$. Com <= é estável.

QuickSort

quickSort(A, l, r)
1. if l < r:
2.    q ← partition(A, l, r)
3.    quickSort(A, l, q)
4.    quickSort(A, q+1, r)
partition(A, inicio, fim)  // Hoare
pivo ← A[inicio]
i ← inicio − 1;  j ← fim + 1
while true:
  do i++ while A[i] < pivo
  do j−− while A[j] > pivo
  if i >= j: return j
  swap(A[i], A[j])
  • Exemplo do slide: $[4, 8, 7, 1, 3, 5, 6]$ com pivô 4 vira $[3, 1, 7, 8, 4, 5, 6]$ e retorna $j = 1$.
  • O trabalho está na divisão (partition, $\Theta(n)$); não há combinação.
  • O caso depende da escolha do pivô (primeiro, último, aleatório) e se lê pelo formato da árvore.
  • Melhor caso (partições equilibradas): $T(n) = T(\lceil n/2\rceil) + T(\lfloor n/2\rfloor) + cn = \Theta(n\log n)$.
  • Pior caso (partições $1$ e $n-1$, ex.: vetor ordenado com pivô no primeiro): $T(n) = T(n-1) + cn$; níveis $cn + c(n-1) + \dots + c$, uma PA, logo $\Theta(n^2)$.
