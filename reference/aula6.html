Aula 6: Divisão e conquista (Parte I)

Paradigma

  • Paradigmas: técnicas genéricas de construção (divisão e conquista, gulosos, programação dinâmica…).
  • Divisão em subproblemas menores do mesmo tipo → conquista recursiva (caso base resolvido direto) → combinação das soluções.
  • Recorrência típica: $T(n) = a\,T(n/b) + f(n)$, com $a$ = nº de subproblemas, $n/b$ = tamanho de cada um e $f(n)$ = custo de dividir e combinar.

Busca binária

binarySearch(A, E, L, R)
1.  if R < L: return −1
3.  m ← floor((L + R) / 2)
5.  if A[m] < E: return binarySearch(A, E, m+1, R)
7.  else if A[m] > E: return binarySearch(A, E, L, m−1)
9.  else: return m
  • Pré-condição: vetor ordenado.
  • Melhor caso: E no meio, sem chamada recursiva, $\Theta(1)$.
  • Pior caso: E ausente, ou achado só na partição de 1 elemento.
  • $a = 1$, $b = 2$, $f(n) = \Theta(1)$: $T(1) = 1$, $T(n) = T(n/2) + \Theta(1)$.

Resolver $T(n) = T(n/2) + c$

$$T(n) = T(n/2^k) + kc,\quad \frac{n}{2^k} = 1 \Rightarrow k = \log_2 n,\quad T(n) = 1 + c\log_2 n = \Theta(\log n).$$

Argumento que divide leva a $k = \log_b n$. Argumento que subtrai leva a $k$ linear.
