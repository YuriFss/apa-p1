Aula 3: Análise assintótica (Parte 3), notação O

Complexidade assintótica

  • Comportamento quando $n \to \infty$. Ignora coeficientes e termos de menor ordem: interessa a taxa de crescimento.
  • Três notações: $O$ (superior, "$\le$"), $\Omega$ (inferior, "$\ge$"), $\Theta$ (restrito, "$=$").
  • Taxas: $1 \prec \log n \prec n \prec n\log n \prec n^2 \prec n^3 \prec 2^n \prec n!$

Definição de O

$f(n) = O(g(n)) \iff$ $f, g$ assintoticamente não negativas e existem constantes positivas $c, n_0$ com

$$f(n) \le c\cdot g(n) \quad \forall\, n \ge n_0.$$

$n_0$: ignora $n$ pequeno. $c$: absorve coeficientes. "Para todo $n \ge n_0$", não "para algum".

Provar pela definição (achar $c$ e $n_0$)

  1. Caminho A: escolha $c$ e resolva $f(n) \le c\,g(n)$ para achar $n_0$. Ex.: $2n + 20 \le 3n \iff n \ge 20$, logo $c = 3, n_0 = 20$.
  2. Caminho B (majorar): descarte negativos e suba cada termo para a maior potência, usando $1 \le n \le n^2 \le \dots$ para $n \ge 1$. Ex.: $5n^2 + 4n - 7 \le 9n^2$, logo $c = 9, n_0 = 1$.

Redação: "Tome $c = \dots$ e $n_0 = \dots$. Para todo $n \ge n_0$, temos [cadeia de desigualdades]. Logo $f = O(g)$. ∎"

Não é $O$: suponha $f \le c\,g$ para todo $n \ge n_0$, divida e chegue a "algo que cresce sem limite $\le c$". Absurdo. Ex.: $n^2 \le cn \Rightarrow n \le c$.

Provar pelo limite

$\lim f/g$conclusão
$0$$f = O(g)$, $g$ cresce mais rápido
constante $0 < L < \infty$$f = O(g)$, mesma taxa
$\infty$$f \ne O(g)$
  • Polinômios: divida pela maior potência de $n$.
  • L'Hôpital em $\infty/\infty$: $(\log_2 n)' = \frac{1}{n\ln 2}$, $(n^k)' = k n^{k-1}$, $(2^n)' = 2^n\ln 2$.
  • Se $\lim f/g = L < \infty$, então $c = L + 1$ serve a partir de algum $n_0$.

Uso

  • Queremos o limite mais apertado (mesma taxa), mas $2n + 20 = O(n^2)$ não está errado.
  • $O$ é usado principalmente no pior caso. No melhor caso é correto, mas $\Omega$ é mais apropriada.
